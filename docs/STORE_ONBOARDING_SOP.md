# 新門市上架 SOP

生效日：2026-09-19
適用範圍：任何新增至 `index.html` 的 `DEFAULT_DATA.sec1` 門市。

## 發布硬條件

每一間新門市必須同時具備下列資料，才可發布：

1. 門市名稱與有效的 LINE 社群連結。
2. 完整且已確認的門牌地址 `addr`。
3. 以完整門牌查核過的 WGS84 數值座標 `lat`、`lng`。

只有地址、或只有可開啟的地圖按鈕，都不算完成；缺少任一座標時不得發布。

## 座標查核流程

1. 以完整縣市、區、道路與門牌在權威地圖或政府門牌資料來源查詢。
2. 確認查詢結果是該門牌，不是同名道路、行政區中心或道路中心點。
3. 將回傳的 WGS84 緯度寫入 `lat`、經度寫入 `lng`；兩者都必須是數值。
4. 在工作紀錄中保留查核日期與來源連結，供發布前回讀。

## 發布前驗證

1. 讀取正式資料，確認新店同時有數值 `lat`、`lng`。
2. 在網站確認該店的「地圖」連結使用座標查詢。
3. 確認距離元件帶有 `data-lat`、`data-lng`，定位成功後可顯示直線距離。
4. 上線後再以正式站重做第 1 至 3 項確認。

## 範圍界線

本 SOP 自生效日起適用於所有新增門市。既有門市若缺座標，必須另行查核與授權補登；不得因新增店而未經確認自動改動既有店資料。
